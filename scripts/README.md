# Reliable-space local-diabatization study

This directory contains separate manuscript-methods and results documents and
a modular Python workflow for all models, diagnostics, LD calculations, and
figures.

## Files

- `models.py`: parameter-dictionary-controlled Hamiltonian models and
  deterministic hard-collapse/ill-conditioning overlap filters.
- `atomistic_data.py`: loading and propagation-ready preprocessing of sparse
  adiabatic `Hvib_ci`/`St_ci` trajectories.
- `ld_active_space.py`: reusable polar-LD propagation, numerical-support
  screening, active-space selection, and convergence procedures.
- `paper_plots.py`: reusable plotting primitives and paper-specific figure
  functions built from them.
- `main.py`: main script that configures the cases and
  orchestrates calculations, summaries, and figures.
- `figures/`: curated figures generated by the program.

## Run

```bash
cd /home/alexvakimov/Projects/Project_Robust_LD/case1_loss_aware_python
python fixed_active_space_ld.py
```

The program uses Matplotlib's non-interactive `Agg` backend and writes only the
17 figures referenced by `RESULTS.md`. It prints fixed-active-space
convergence, overlap-rank, candidate acceptance, and TiO2/C20 summaries. NumPy,
SciPy, and Matplotlib are required.

The reusable `prepare_atomistic_trajectory` function in `atomistic_data.py`
loads raw `Hvib_ci`/`St_ci` data. `infer_constant_active_space` and
`diagnose_fixed_active_spaces` in `ld_active_space.py` infer a trajectory-wide
upper rank bound and screen proposed square state blocks at every time-step
interval. No common trajectory basis, Hamiltonian projection, or
rediagonalization is used.
For the TiO2 data, `Hvib_ci` is treated as a vibronic
Hamiltonian in the adiabatic representation; its real diagonal—not an
eigendecomposition of the full vibronic matrix—defines adiabatic energy
ordering. The precomputed `St_ci` files are loaded directly as the time
overlaps; they are not reconstructed from `Hvib_ci`, and no diabatic
Hamiltonian is required. The TiO2 population example uses polar LD from the
same initial state in fixed spaces with $N_A=6$, 8, and 11.

The C20 example is loaded from `Project_Kosar_fullerenes/res-tddft-energy` by
the same adiabatic-data path. It screens every leading fixed size from 2 to 41,
uses the largest accepted block only as an internal population comparison, and
demonstrates that block support need not vary monotonically with dimension.

The deterministic 30-state model contains six explicit dense energy bands.
The workflow compares candidate boundaries that close complete bands with cuts
through their interiors. It is propagated for 80 fs with a 0.5 fs time-step
interval; Hamiltonian matrix elements remain in atomic units while plotted
energy levels are converted to eV. The deterministic intraband and interband
reference spacings are 0.0012 and 0.0090 Hartree, respectively, making
active-space truncation effects visible without removing the band structure.
`energy_gap_candidate_guidance.png` summarizes the
recommended hierarchy: persistent energy gaps propose chemically plausible
fixed spaces, raw overlap singular values decide numerical support, and
population convergence decides whether a supported space is large enough.

The three-state figure contrasts full-space LD, a deliberately nonunitary
two-state contraction, and unitary-forced polar LD. All production-style
dense-manifold, stress-test, TiO2, and C20 calculations use norm-conserving square
polar propagators; singular values are evaluated from the raw overlap blocks
before polar orthogonalization.

## Model parameters and stress filters

Every model is controlled by an explicit dictionary. For example:

```python
from models import build_model_trajectory, model_parameters

params = model_parameters(
    "dense_manifold",
    overlap_filter="ill_conditioned",
    filter_noise_scale=1.0e-4,
)
trajectory = build_model_trajectory(params)
```

Set `overlap_filter` to `"none"`, `"hard_collapse"`, or
`"ill_conditioned"`. The latter two modify the model time overlaps
independently of the Hamiltonian and therefore serve only as numerical stress
tests; their reference Hamiltonian energies must not be interpreted as
self-consistent energies of the corrupted overlap directions.
